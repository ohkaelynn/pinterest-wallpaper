# Contributing

Contributions from both humans and AI-assisted workflows are welcome.

- **Be transparent:** Mention in your PR if AI tools helped write the code, and make sure you've tested it locally.
- **Follow [AGENTS.md](AGENTS.md):** Do not weaken rate limits, add aggressive scraping, store passwords, add telemetry, or hit live Pinterest endpoints in automated tests.
- **Keep it simple:** Prefer small, readable C# / .NET 8 changes over unnecessary abstractions.
